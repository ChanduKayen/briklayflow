⚖️ Intent Arbitration — handleSessionReply() · _handlers.ts
Mandatory gate before any session state is read. Runs classifyIntent() first.

🔄 Session State Machine (soft-lock) — _session.ts + _handlers.ts
Sessions have a 10-min TTL. Arbitration can break out of any state (except AWAIT_IMAGE_CONTEXT).
AWAIT_AMOUNTAmount missing — "How much? e.g. 5000"
↓ user replies number → advance
AWAIT_PAYEEPayee missing — "Who was paid?"
↓ user replies name → advance
AWAIT_PAYEE_CHOICEAmbiguous payee — shows 1/2/3 options
↓ user replies digit → advance
AWAIT_PROJECTMultiple active projects — "Which project?"
↓ user replies digit → POST entry + clearSession
AWAIT_IMAGE_CONTEXTImage received — "Add a note" (45s window)
↓ user note → update entry → PENDING · background AI still running

💰 handleFinancial() Decision Chain — max 1 question per entry
1 Amount missing? → "How much? e.g. 5000" → AWAIT_AMOUNT
2 Payee absent? → "Who was paid?" → AWAIT_PAYEE
3 Payee LOW confidence + fuzzy matches? → numbered list → AWAIT_PAYEE_CHOICE
4 >1 active projects, no project hint? → numbered list → AWAIT_PROJECT
5 All fields present → INSERT rough_entry + trigger ai-extract-entry + send "✅ Added" reply
